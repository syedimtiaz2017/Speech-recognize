# Speech Emotion Recognition

This project detects emotions from speech using a machine learning pipeline.

## Features
- Upload WAV audio
- Predict emotion (happy, sad, angry, neutral)
- Display confidence scores

## Tech Stack
- Python
- Librosa (audio features)
- Scikit-learn (RandomForest)
- Streamlit (UI)

## Setup

pip install -r requirements.txt

## Train Model

python train_model.py

## Run App

streamlit run app.py
